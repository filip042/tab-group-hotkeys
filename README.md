# Tab Group Hotkeys

An extension that adds keyboard shortcuts for working with Firefox's built-in tab groups.

Install from [Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/tab-group-hotkeys/).

## Shortcuts

| Action | Default Shortcut |
| --- | --- |
| New tab in current group | `Ctrl+Alt+N` |
| New tab in chosen group | `Ctrl+Alt+G` |
| Move tab to group | `Ctrl+Alt+A` |
| Next group | `Ctrl+Alt+PageDown` |
| Previous group | `Ctrl+Alt+PageUp` |
| Collapse or expand current group | `Ctrl+Alt+O` |

Clicking the toolbar button shows the current shortcuts.
See [Mozilla's support page](https://support.mozilla.org/en-US/kb/manage-extension-shortcuts-firefox) for how to change the default key combinations.

## Requirements

Firefox 140 or later.
